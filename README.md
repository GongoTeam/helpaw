# 🐾 Helpaw

**Helpaw** — це веб-застосунок, де кожен може поділитися своєю історією порятунку тварини або прочитати зворушливі розповіді інших людей. Ми прагнемо популяризувати адопцію, надихати на добрі вчинки та показувати, як тварини змінюють життя на краще.

## 🚀 Основні можливості

- 📖 Перегляд історій тварин, які знайшли новий дім  
- 🐶 Додавання власної історії через просту форму  
- 🖼️ Завантаження фото у форматі зображення (опціонально)  
- 💚 Сучасний та адаптивний інтерфейс для користувачів  

## 🛠️ Технології

- React – для побудови інтерфейсу  
- React Router – для маршрутизації між сторінками  
- JavaScript – для логіки взаємодії з формами  
- FileReader API – для попереднього перегляду зображень  
- CSS-in-JS (inline styles) – для стилізації компонентів

## 💡 Можливі покращення

- Збереження історій у localStorage або на сервері
- Лайки або рейтинги історій
- Фільтрація за типом тварини (кіт, пес тощо)
- Пошук за іменем
- Модерація історій перед публікацією
